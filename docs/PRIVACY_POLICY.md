## 위치정보

Wearon은 **오늘 날씨에 맞는 코디를 추천하기 위해서만** 기기의 위치를 사용합니다.

| 항목 | 내용 |
|---|---|
| 수집 정보 | **대략적인 위치**(`ACCESS_COARSE_LOCATION`)만 사용합니다. 정밀 위치(GPS)는 요청하지 않습니다 |
| 사용 목적 | 현재 위치의 날씨(기온·날씨 상태·습도·풍속) 조회 |
| 정밀도 | 앱이 위도·경도를 **소수 둘째 자리(약 1km 범위)로 반올림**해 서버로 보냅니다. 서버도 한 번 더 같은 방식으로 반올림하며, 정밀한 좌표는 서버에 도달하지 않거나 즉시 버려집니다 |
| 제3자 제공 | 반올림된 좌표가 날씨 조회를 위해 **OpenWeatherMap**(OpenWeather Ltd.)에 전송됩니다. 이 요청은 사용자 기기가 아니라 Wearon 서버가 보내므로 사용자의 계정·기기 정보는 함께 전송되지 않습니다 |
| 저장 | 위치를 **계정(사용자)에 연결해 저장하지 않습니다**. 날씨 응답을 재사용하기 위해 서버가 반올림 좌표를 **캐시 키로 최대 30분** 보관하고 그 뒤 자동 삭제합니다. 로그에도 좌표를 남기지 않습니다 |
| 선택권 | 위치 권한은 **선택**입니다. 허용하지 않거나 위치를 얻지 못하면 **서울** 기준 날씨로 추천합니다. 권한은 기기 설정에서 언제든 철회할 수 있습니다 |
