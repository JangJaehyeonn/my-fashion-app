# Wearon 화면 명세 (v2, 2026-11-21)

프로토타입(claude.ai 디자인 캔버스 "Wearon 살까 말까 프로토타입")을 글로 옮긴 것이다. 앱 화면 요구사항(issues.toml의 area = "android")은 이 문서를 기준으로 구현한다.
숫자와 문구 예시는 시연용이다. 실제 값은 API에서 받는다.

## 공통

- 테마: 기존 `ui/theme/Theme.kt`의 `WearonColors`, `WearonShapes`를 그대로 쓴다. 새 색은 아래 두 개만 추가한다.
  - 강조 갈색 `#7A5420` (비슷한 게 있어요 배지, 잘 안 입는 옷, 옷장 빈틈 제목)
  - 보조 회색 글자 `#6B6458`, 흐린 글자 `#8A8378`, 구분선 `#ECE7DE`
- 모서리: 카드 8dp, 칩·배지·작은 버튼 4dp, 사진 6~8dp
- 글꼴 굵기: 화면 제목 900, 섹션 제목 700, 본문 400~500
- 하단 탭 4개: 홈 / 옷장 / 쇼핑 / 마이. 선택 탭은 아이콘·글자 #1A1A1A + 굵게, 나머지 #8A8378
- 터치 영역 최소 44dp. 아이콘만 있는 버튼은 contentDescription 필수
- 이모지 쓰지 않는다

## 홈 탭

위에서 아래로:
1. `WEARON` 로고 (24sp, 900, 자간 2)
2. 날씨 카드 (베이지 배경): 큰 기온(40sp, 가늘게) · 날씨 · 오른쪽 지역명
   - 아래 동선 타임라인(FR-28): "8시 3° → 13시 12° → 19시 7°" + 오른쪽 "일교차 9°"(일교차 8° 이상이면 굵게)
   - 일교차 규칙 적용 시 한 줄 "외투를 벗어도 괜찮은 코디로 골랐어요", 비 예보면 "비 소식이 있어 스웨이드·흰 신발은 뺐어요"
3. "오늘은 어떤 날인가요?" + 상황 칩 6개 (데일리/출근/데이트/운동/여행/면접). 선택 칩은 검정 배경 흰 글자
4. "오늘의 추천 코디" + 오른쪽 "{상황} · N개". 코디 카드 가로 스크롤(카드 너비 약 300dp)
   - 카드: LOOK 01 (900, 자간) + 스타일 태그 / 옷 사진 3~4개(아우터→상의→하의→신발) + 옷 이름 / 추천 이유 2줄
   - 제목 아래 흐린 글자 "입을 수 있는 옷 N벌 중에서 · 세탁 중 N벌 제외"(FR-27)
   - revived 조합(FR-29)은 해당 옷 사진 위에 갈색 작은 배지 "오랜만이에요"
   - 카드 아래 버튼: **"오늘 이거 입었어요"** (테두리 버튼). 누르면 베이지 배경 + 체크 아이콘 + "착용 기록에 남겼어요"로 바뀌고 다시 누를 수 없다. 그 아래 텍스트 버튼 "입은 옷 세탁에 넣기"(누르면 "세탁 바구니에 넣었어요")
5. 이번 주 착용 기록 카드 (테두리): 왼쪽 "이번 주 착용 기록 N회", 오른쪽 "가장 많이 입은 옷: {이름} · N회"

옷장이 비어 있으면 4번 대신 기존 "옷장에 옷을 등록하면…" 안내를 보여준다.

## 옷장 탭

1. 제목 "옷장 {N}" + 오른쪽 검정 "＋ 옷 등록" 버튼
2. **요약 줄** (베이지, 3칸, 칸 사이 세로 구분선)
   - 만들 수 있는 코디 {N} / 이번 달 착용 {N}회 / 잘 안 입는 옷 {N}벌 ›(갈색, 누르면 '적게 입은 순' 정렬 + 전체 카테고리)
3. 카테고리 칩 가로 스크롤: 맨 앞 "세탁 바구니 N"(세탁 중 옷이 있을 때만, 테두리 칩; 누르면 세탁 중 옷만 + 하단 "세탁 끝" 일괄 버튼), 이어서 전체·상의·하의·아우터·신발·기타, 각 개수 포함. 둥근 칩(높이 38dp, 완전 둥글게). 선택은 검정 배경
4. 왼쪽 "N벌", 오른쪽 정렬 텍스트 버튼 3개: 코디 많은 순(기본) / 적게 입은 순 / 최근 등록. 선택은 굵게 + 밑줄
5. 2열 그리드 (세로 간격 18dp, 가로 10dp). 카드:
   - 사진 영역 높이 약 210dp, 베이지 배경
   - 사진 왼쪽 아래: 검정 배지 **"코디 N개"** (미분류는 "코디 계산 전")
   - 사진 왼쪽 위 배지(하나만, 우선순위 순): 세탁 중 → 흰 배경 검정 글자 "세탁 중" + 사진 50% 흐리게 / 미분류 → 갈색 "미분류 · 확인 필요" + 점선 테두리 / 착용 0회 → 흰 배경 갈색 글자 "잘 안 입는 옷" / 방금 산 옷 → 검정 "NEW" + 검정 테두리
   - 이름 15sp 굵게
   - 색상 점(10dp) + "카테고리 · 색상"
   - "착용 N회" (0회면 갈색 "아직 안 입었어요")
6. 카드를 누르면 옷 상세(FR-02)

## 쇼핑 탭

### 쇼핑 홈
1. 제목 "쇼핑"
2. 검정 카드: 작은 글씨 "매장에서 고민될 때" / 제목 "살까 말까? 내 옷장이랑 비교해 드려요" / 버튼 3개 가로(촬영: 흰 배경, 갤러리·상품 주소: 테두리) / 안내 "옷만 나오게 찍으면 더 정확해요"
3. 요약 2칸(베이지): 내 옷장 N벌 / 만들 수 있는 코디 N개
4. (출시 후, FR-25) 다음에 살 옷 추천: 행마다 사진·이름·이유·검색어(갈색 작은 글씨)·오른쪽 큰 "+N" 과 "코디"
5. 최근 판정 목록: 사진(또는 카테고리 아이콘) · 이름 · "날짜 · 판정" · 오른쪽 결과 배지(샀어요=검정 / 안 샀어요=연베이지)
6. 가상 피팅 카드(테두리): "가상 피팅" / "판정 결과에서 바로 입어볼 수 있어요" / ›

옷장 5벌 미만: 검정 카드 아래 "옷장에 5벌 이상 있어야 비교할 수 있어요" + 옷장으로 가기, 버튼 3개 비활성화.

### 촬영
- 검정 배경, 상단 닫기(X) + "옷만 나오게 찍어주세요"
- 가운데 뷰파인더(모서리 가이드 선 4개), 하단 흰 셔터 버튼(76dp)

### 확인 단계
- 고른 사진, "가격 (선택)" 숫자 입력, "비교하기" 버튼

### 분석 중
- 아이보리 배경, 사진(베이지 카드), "옷장이랑 비교하는 중" / "보통 5초 안에 끝나요"
- 단계 3개: 옷 분석 (종류·색·소재) / 내 옷장과 비교 / 늘어나는 코디 계산. 끝난 단계는 검정 원 + 체크, 진행 중은 검정 테두리 원 + 굵은 글자, 대기는 회색

### 결과
위에서 아래로 (하단 고정 버튼 높이만큼 아래 여백):
1. 상단 뒤로(←) + "살까 말까"
2. 사진(96×120dp) + 이름(17sp 굵게) + "가격 · 직접 입력" + 속성 칩들 + 밑줄 텍스트 버튼 "AI가 본 정보가 틀렸나요? 고치기"
3. **+N 코디 블록** (검정 1dp 테두리 카드): 왼쪽 큰 "+N"(48sp, 900) + "코디", 오른쪽 "이 옷을 사면 코디가 늘어나요" / "지금 A개 → B개" / 한 줄 설명. 아래 구분선 후 "한 번 입을 때 약 N원 · 1년에 예상 N회"(costPerWear null이면 흐린 글자 "착용 기록이 쌓이면 1회당 가격을 알려드려요")
4. 판정 카드
   - SIMILAR: 베이지 배경, 배지 갈색 바탕 흰 글자 "비슷한 게 있어요"
   - BUY: 검정 배경 흰 글자, 배지 흰 바탕 검정 글자 "사요"
   - THINK: 흰 배경, 배지 연베이지 바탕 "고민해보세요"
   - 배지 / headline(20sp 굵게) / 이유 3줄(글머리 기호)
5. 비슷한 내 옷 (있을 때만): 흰 카드 행. 사진 64dp · 이름 · 다른 점 한 줄 · 착용 N회 · 오른쪽 갈색 굵은 "92%"
6. 내 옷이랑 만드는 코디 (있을 때만): 제목 + 오른쪽 "N개 중 대표". 가로 스크롤 카드, 카드마다 라벨(출근/데일리…) + 옷 사진들. 새 옷은 검정 테두리 + 왼쪽 위 "NEW"
7. 옷장 빈틈 (gap 있을 때만): 베이지 박스, 갈색 정보 아이콘 + 갈색 "옷장 빈틈" + 문장
8. 하단 고정 버튼 3개: 안 살래요(테두리) / 입어보기(테두리) / 살래요(검정, 가장 넓게 1.3배)

### 완료
- 검정 원 체크(56dp), "옷장에 등록했어요", "만들 수 있는 코디가 B개가 됐어요. 사진을 다시 찍지 않아도 돼요.", 등록한 옷 카드, "쇼핑으로 돌아가기"(검정)

## 마이 탭

1. 제목 "마이"
2. 프로필: 원형 아바타(64dp) + 닉네임 + 로그인 방식(아이디 로그인 / Google / Kakao)
3. 이번 달 요약 3칸(베이지): 이번 달 착용 기록 N회 / 살까 말까 N회 / 늘어난 코디 +N개
   - 그 아래 "살까 말까로 산 옷" 목록(있을 때만): 사진 48dp · 이름 · "예상 1회 N원 → 지금 1회 N원"(착용 0회면 갈색 "아직 안 입었어요")
4. 내 체형·취향 카드(베이지): 제목 + "코디 추천과 살까 말까에 반영돼요" + 오른쪽 "수정". 흰 칸 2×2: 키 / 몸무게 / 체형 / 스타일
5. 설정 목록(테두리 카드, 행 52dp, › 아이콘): 체형·취향 수정 / 출퇴근 시각·이동 방식(FR-28) / 비밀번호 변경(아이디 가입자만) / 가상 피팅 사진 전송 동의(오른쪽 상태) / 개인정보처리방침 / 이용약관 / 로그아웃 / 회원 탈퇴(흐린 글자)
6. 맨 아래 "Wearon v1.0"
